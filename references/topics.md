# 从素材扩展选题

读取已确认账号方向、本轮新增素材的完整原始内容和已有选题/已发布作品。library context 提供上下文，长输出分批读；只有标题或 AI 摘要的条目不能声称读过全文。template-cases.md 用于讲解模板，不能代替本轮采集。

## 扩展

先理解具体问题和表达模板，再换工具领域、人群、任务、场景或结果，形成可分别制作的内容。

参考“22s搞懂！7类AI工具如何选择【专业vs免费】”，可以展开：

- 7类 AI 作图工具如何选择【专业vs免费】。
- 7类 AI 写作工具如何选择【专业vs免费】。
- 电商运营常用的 AI 工具怎么选【付费vs免费】。

这些只是方向，不代表7类工具及免费条件已实测。每题说明要比较的任务、展示什么、还需验证什么。换领域可以形成独立题；不能仅因换了工具名一律判重复，也不能做近义改写凑数。去重看具体问题、人群、场景与主要交付。

三类内容：

- **互动贴**：真实易接话的问题，不捏造购买或踩坑经历。
- **起号视频**：参考模板展示工具、操作、概念或效果；明确自己的材料与制作形式。
- **商单类视频**：一个功能解决一个任务，展示真实操作/结果；未合作的叫自主样片，不编品牌合作。制作衔接关卡4和已有商单脚本 Skill。

素材阶段只筛相关性。用户暂时缺工具或录屏，影响准备度，不直接否定选题潜力。

## 讨论后入库

先给少量候选：题目、来源、切入点、形式、待准备材料。有多少成立给多少，不强制10条。用户选中后入库；已授权直接入库的范围不重复确认。

由 AI 整理 JSON 数组，通过标准输入交 `library.py topics-import`：

```json
[
  {
    "title": "实际选题",
    "kind": "起号视频",
    "core_question": "要回答的具体问题",
    "audience": "实际目标观众",
    "scene": "具体使用场景",
    "angle": "相比参考作品，自己改变什么、交付什么",
    "format": "已选择的制作形式，或待选择",
    "references": ["已经入库的实际素材ID"],
    "materials_needed": ["需要自己准备的素材"],
    "verification_needed": ["还需核对的事实"]
  }
]
```

不要把示意结构当成真实内容入库。程序拒绝无效来源，保留已有选题，只能检查归一化重复；AI还需做语义去重。

## 持续制作

选一题标制作中，接前面关卡的脚本、拍摄、剪辑、封面/标题/正文教程。实际发布后加真实作品链接、标已发布，不自动发布。质量改进沿用关卡3的作品对标方法，不另要求数据复盘。

用户要求新素材补题，优先处理新增/未读内容，保留已有决定。可以提出新的关键词/对标建议，由用户决定是否改配置，不扩大付费采集范围。
